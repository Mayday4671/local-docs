# Windows 交付说明

日期：2026-09-28。当前版本：0.10.2 开发测试版。

## 安装包

`release/0.10.2/local-docs-0.10.2-x64-setup.exe`，116,467,015 字节（约 111 MiB）。

在线下载：[EXE 安装包](https://github.com/Mayday4671/local-docs/releases/download/v0.10.2/local-docs-0.10.2-x64-setup.exe) · [发布说明](https://github.com/Mayday4671/local-docs/releases/tag/v0.10.2) · [SHA256SUMS.txt](https://github.com/Mayday4671/local-docs/releases/download/v0.10.2/SHA256SUMS.txt)。以测试版发布。

保存并关闭旧版窗口后，双击 EXE，按照中文向导安装。应用包含运行环境、界面、数据库引擎和本地文档解析，不需要另装 Node.js、npm、Office、WebView2 或服务器。安装与日常使用无需联网，可用 U 盘携带安装包。安装包尚未数字签名。

发布资产仅包含 EXE 和校验文件，不含用户的本地资料库、个人文档或备份。已检查包内路径，没有打入用户数据库或 Office 文档；新电脑会创建空文档库，已有资料通过应用完整备份和恢复迁移。

默认数据位置改为 `<安装目录>/data/library/`。“设置 → 文档库位置 → 修改位置”可选择其他可写空文件夹，迁移校验后即时切换、重启记忆。旧副本保留，不自动同步。旧版 `%APPDATA%/local-docs/library/` 在首次启动时自动迁入默认位置，失败时继续使用旧库并在设置中说明。0.10.0 的升级 / 卸载清理保留 data；手动删除安装目录仍会删除其中的资料。首次安装目录不可写时可选其他位置；已配置的磁盘失联不会创建空库替代。

地址配置和浏览器缓存仍在 `%APPDATA%/local-docs/`，其中 `storage-location.json` 只保存文档库路径。本次不改变 schema v5 或备份 v2；含 0.9.0 新增文件类型的备份应使用 0.9.0 或更新版本恢复。跨电脑继续使用完整备份 / 恢复。

## 本次修正

0.10.2 将首页“收起预览”从菜单移到预览区右上角，使用常驻的“×”图标，选中文件和空状态保持一致。收起后，列表右上角显示展开图标，点击恢复预览及此前的分栏宽度；两个菜单中不再显示重复的收起 / 展开文字项。

0.10.1 为安装向导设置原生的 `InstallDir`，浏览文件夹时立即补上英文子目录 `local-docs`。例如选择 `D:\Soft` 后，路径框显示 `D:\Soft\local-docs`；默认资料位于 `D:\Soft\local-docs\data\library`。直接选中已有的 local-docs 文件夹不会重复追加。升级保留已登记的安装位置。

0.10.0 新增安装目录默认存储和设置内位置迁移。迁移包含所有仍被引用的文件 / 历史 / 附件对象及完整数据库记录，逐项校验后切换；取消、损坏、目标非空、地址写入失败均保留原库。新产生的恢复前备份随当前库保存，已有历史备份留在旧目录。安装包改为只清理已知程序文件，避免递归删除整个安装目录。详见 [0.10.0 存储位置验收](0.10.0存储位置验收.md)。

0.9.0 取消格式导入白名单，新增 PDF 离线翻页 / 缩放、TXT / SQL / CSV / JSON / 代码文本只读预览与搜索、独立图片预览。其他普通文件可原样收纳和导出。首页支持原生多文件拖入当前分类，移除侧栏“未分类”入口，原资料保留在“全部文件”。PDF 阅读组件、worker、CMaps、字体、解码器和许可证随安装包打包。详见 [0.9.0 验收](0.9.0文件格式与拖入验收.md)。

0.8.1 移除 Word / Excel 页面重复的“编辑内容”按钮。当前状态改为“编辑中 / 阅读中”文字提示，编辑时仅提供“阅读与标记”，阅读时提供“编辑”或“返回编辑”。切换保留未保存内容、恢复草稿和标记流程，不自动提交正文。没有数据库升级或新增依赖。

0.8.0 新增历史版本内容差异：在“历史版本”中点击“查看差异”，任选两个保存版本，按 Markdown 行、Word 段落或 Excel 工作表 / 单元格左右对比，可筛选变化和分页。只读查看不会覆盖未保存编辑及草稿。首页“编辑”和新建 Office 文件直接进入编辑状态，无需再次点击“编辑内容”。对比范围、边界和截图见 [0.8.0 验收](0.8.0历史对比与直接编辑验收.md)。

0.7.1 修复 Word 段落制表位属性被误判为复杂内容，标题和普通表格文字可编辑，空白普通段落可输入。成功消息约 3 秒自动关闭，连续操作重置计时，错误与处理中提示继续保留。详见 [0.7.1 验收](0.7.1Word编辑与提示修复验收.md)。

0.7.0 替换 Office 逐项表单：Word 在文档页面内直接改字，表格文字保留在表格中，提供查找与缩放；Excel 使用行列网格、工作表标签、单元格输入栏，支持合并格显示、空白格输入和坐标定位。草稿、历史和原件保护继续生效。字体排版、结构编辑和公式计算尚未实现。详细范围见 [0.7.0 验收](0.7.0Office页面与网格编辑验收.md)。

0.6.2 将调宽功能扩展到首页文件列表 / 文档预览。拖动两者之间的分隔条调节，双击或 Enter 恢复默认比例；收起再展开、返回首页、重启后保留宽度。首页与编辑页分别记忆。窄面板自动减少次要列表列，并将预览操作按钮排成两行，最小可用宽度受保护。

0.6.1 新增 Markdown 编辑 / 预览分栏调宽。拖动中间分隔条调整比例，双击或 Enter 恢复均分，左右方向键微调，Escape 取消正在进行的拖动。比例在本机记忆，返回文档和重启后恢复；窄窗口及历史面板打开时自动保护两边可用宽度，不修改正文或历史。

0.6.0 新增列表星标与批量收藏、Markdown / Word 正文 / Excel 单元格标记、高亮颜色和备注、标记集中查看与检索。补齐恢复草稿、图片附件和文内查找，并加入新建及基础 Word / Excel 内容编辑。修改后保存真实文件和历史版本；编辑范围与限制见 [0.6.0 验收记录](0.6.0收藏标记与内容编辑验收.md)。

0.5.0 补齐分类改名、移动、删除和文件批量移动；删除分类转移文件并保留内容、历史及回收站状态。文件夹导入先预览再确认，保留目录和空分类，提供重复处理、进度、取消和失败清单。相同内容可跳过，不同内容自动编号，原件不变。详见 [0.5.0 验收记录](0.5.0分类整理与文件夹导入验收.md)。

0.4.0 在设置中提供完整备份、校验预览与恢复，恢复前自动保存当前文档库。新增分类子树和整个文档库的目录导出，保留空分类，处理重名并提供结果清单。进度和取消已接入，恢复提交阶段禁止中断。详见 [0.4.0 验收记录](0.4.0备份恢复与导出验收.md)。

Markdown 侧栏和编辑页支持表格、任务列表、删除线及代码缩进；Excel 侧栏改用真实工作表网格，并按数字格式显示日期、百分比、千分位和补零编号。修复 Office 编码换行和 Word 宽表访问问题。

0.3.1 将主题入口从设置弹窗移至主界面和阅读 / 编辑页右上角。点击主题按钮即可选择浅色、深色、跟随系统，立即生效并自动记忆；键盘方向键、Esc 与点击菜单外关闭可用。切换不会重新读取文档，未保存的编辑内容保持不变。

## 尚未完成的产品能力

本包不是完整 V1.1。Word / Excel 已可新建和基础内容编辑，但完整排版、工作表管理、图表和公式重算未实现。恢复草稿、Markdown 图片、PDF / 独立图片收纳、文件拖入、版本内容比较和应用内换盘已实现；PDF 全文索引 / OCR、日期筛选和定期备份仍未完成。Word 复杂版式、Excel 条件格式和复杂样式仍有兼容性限制；编辑网格已显示合并区域，阅读网格仍提示范围。
