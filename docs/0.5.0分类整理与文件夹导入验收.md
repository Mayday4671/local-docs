# 0.5.0 分类整理与文件夹导入

日期：2026-09-27。所有测试使用独立数据目录与合成文件，不读取日常资料库。

## 新增使用入口

- 分类树每项右侧的“⋮”：修改名称或上级分类；删除时再次确认，并选择文件转移位置。对子分类一并生效，回收站文件仍留在回收站。
- 列表或网格勾选文件 →“移动到分类”：批量转移，不改变正文、历史、标签或收藏。
- 文件列表右上角“⋮”→“导入文件夹”：先显示来源、数量、目录与跳过原因，确认后导入。保留根目录和空文件夹。
- 导入中显示进度，可取消；已完成的文件与分类保留。失败项逐项列出，修正后重新选择相同目录即可重试。

主题按钮仍在右上角；本次弹窗沿用浅色、深色和跟随系统。

## 重复与失败规则

同名分类复用。默认跳过同分类中名称与内容都相同的文件，包含此前自动生成的编号副本；也可选择全部保留。同名但内容不同自动加 `（2）` 等编号，不覆盖已有记录。回收站文件不参与重复跳过，重新导入不会自动恢复回收站文件。单独“添加文件”入口仍按每次新增副本处理。

源文件不会修改。目录或文件在预览后被替换、移走或修改时，该项报告失败；错误编码也独立失败，其余项目继续。目录创建失败时，其下文件不会错误地落到其他分类。进程被强制终止时可能已完成一部分导入；没有持久化的暂停任务，可重新选择目录并使用默认重复跳过。

删除分类会丢弃原分类结构，没有单步撤销；文件内容与历史保留。如要恢复原分类结构，可从之前创建的完整备份恢复。

## 限制

每次扫描最多 10000 个项目、32 层；最多导入 5000 份支持的文件、2000 个目录、2 GiB 内容。Markdown 单文件 5 MiB，Office 单文件 100 MiB。预览目录和跳过原因各显示前 100 项，结果失败列表保留全部本批失败项。

不支持符号链接 / 目录联接导入，跳过应用自身存储目录。Office 文件保管与可完整预览范围不同，解析超限仍可导出原件。文件读取异步，但摘要、对象持久化及数据库提交仍同步；大文件提交可能短暂阻塞。未进行实际磁盘耗尽、断电或最大容量压力验收。

Office 内置编辑、拖放、自动保存和附件支持不在此版本已完成功能中。
