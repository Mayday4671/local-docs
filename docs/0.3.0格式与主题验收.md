# 0.3.0 格式与主题验收

日期：2026-09-27。范围为当前支持的 `.md`、`.markdown`、`.docx`、`.xlsx`，包括大写扩展名。全部测试使用自行生成的示例资料，未复制用户截图中的私人内容。

## 问题与修复

- Markdown 使用了基础语法解析，未启用 GFM，导致竖线表格显示成文字。现在侧栏和编辑页共用同一渲染组件，支持表格、任务列表和删除线；长表格局部横向滚动，代码缩进保留。
- Excel 侧栏原先只显示前十段提取文字。现在与完整阅读器共用工作表网格，可切换工作表、选择单元格和查看公式。
- Excel 原先直接显示数字存储值。现在按内置或自定义数字格式显示日期、百分比、千分位和补零编号，同时保留原始值；公式使用文件内缓存结果，不计算公式。格式隐藏的数值与真正缺少缓存结果已区分。
- Office XML 中的数字字符引用原先没有正确解码，导致部分换行和中文显示为编码。Word 和 Excel 使用一致的解码选项。
- Word 宽表增加可横向滚动的局部容器，保留合并单元格和文档自身配色。
- 增加浅色、深色、跟随系统三种主题。“设置 → 外观主题”立即切换并自动记忆；主界面、编辑器、阅读器、弹窗和原生标题栏同步。Word 纸张保持原文配色。

## 数据兼容

schema v4 增加主题设置，清除可重建的旧 Office 预览缓存。已有资料在首次阅读或搜索时自动重建预览，不必重新导入；不修改文件对象、分类、标签、历史版本或最近使用时间。迁移测试覆盖 schema v1、v2、v3。

## 检查范围

- 20 项存储与解析测试：历史版本、迁移、源文件保护、主题保存、日期系统、公式缓存及异常文件等。
- Markdown：中文表格、末尾空列、对齐、转义竖线、CRLF、UTF-8 BOM、任务列表、删除线、代码空格和长表，侧栏与编辑页分别验证。
- Word：带格式文字、宽表、合并标题、多行、数字编码中文、图片、页眉页脚、正文搜索定位；侧栏和完整阅读器分别验证。
- Excel：多工作表、隐藏表、真实稀疏坐标、共享字符串、布尔值、多行、错误结果、日期、百分比、千分位、补零、1904 日期系统、已缓存和未缓存公式。
- 主题：浅色 / 深色逐项检查；窗口背景和系统主题同步；深色与跟随系统重启保留；系统外观变化在测试应用内模拟，不修改 Windows 设置。
- 导入、导出与源文件逐字节比较；禁止测试中的 HTTP/HTTPS；页面未捕获异常检查；1536 px 和 1000 px 窗口布局检查。
- 原有分类、标签备注、收藏、搜索、版本恢复、回收站、列表 / 网格和路径复制流程继续回归。

测试入口：`npm test`、`npm run test:formatting`、`npm run test:packaged`。后者直接启动当前版本 `release/0.3.0/win-unpacked/我的文档库.exe`，依次执行基础、Office、界面和格式主题四组桌面脚本。安装包交付与最终结果见 [Windows 交付说明](Windows交付说明.md)。

## 边界

这是对已支持格式的代表性回归，不表示所有 Office 文件完全兼容。Word 复杂分页、域和修订仍可能不同；Excel 图表、条件格式、合并区域视觉效果及完整样式仍未实现。Markdown 本地附件、远程图片和原始 HTML 不渲染。PDF、图片、旧式 `.doc/.xls` 尚不支持。Office 仍只读。
