# 0.10.0 存储位置验收

日期：2026-09-28。平台：Windows x64，测试使用合成资料和独立目录。

## 使用方式

新电脑首次运行，文档库位于 `<安装目录>/data/library/`。左下角“设置”显示当前绝对路径和默认路径，点击“修改位置”，选择空文件夹，核对迁移信息后点击“迁移并使用此位置”。完成后立即使用新库，重启仍保持。

文件、分类、收藏、标签、备注、内容标记、附件、恢复草稿、回收站、历史版本与主题均保留。旧位置留有一份不再同步的副本；以前生成的恢复前备份仍在旧目录，新产生的恢复前备份位于新库的 `recovery-backups`。

旧版 `%APPDATA%/local-docs/library/` 在首次启动时自动复制到安装目录，旧副本保留。如果默认位置不可写、空间不足或非空，则继续使用旧位置并在设置中说明；之后可手动修改。首次使用时目录不可写，可通过提示选择可写空文件夹。已配置的文档库丢失或磁盘未连接时，不自动创建空库替换，需连接原磁盘或选择已有库。

路径指针 `storage-location.json`、窗口配置和浏览器缓存仍在 `%APPDATA%/local-docs/`。这不是免安装便携版；跨电脑请使用完整备份 / 恢复。

## 数据保护

- 原生文件夹选择器绑定一次性迁移预览；拒绝当前目录、父子目录、链接、非空目标和应用资源目录。安装目录内仅允许 data 下的位置。
- 复制所有有效引用的对象，核对大小及 SHA-256；使用 SQLite 在线备份包含 WAL 中的数据，校验数据库完整性和迁移前后记录。
- 目标同盘暂存，复制完成后再次检查目标是否仍为空，然后发布新库并原子更新地址。失败或取消仍使用原库，不删除旧副本。
- 切换期间阻止并发写入，关闭旧 Office 解析服务，重新绑定数据库、导入、备份和附件读取。取消在复制阶段可用；最后提交阶段不可中断。
- 0.10.0 的 NSIS 升级 / 卸载只移除已知程序文件及 resources / locales，不递归删除安装目录，保留 data 和其他用户文件。

## 验证结果

类型检查、格式检查、生产构建、85 项单元测试通过。新增 11 项存储测试覆盖首次创建、旧版迁移、在线 WAL 内容、全部记录和原始字节、路径约束、目标中途变化、取消、复制失败、损坏源对象、配置提交失败、磁盘失联恢复和默认迁移失败回退。启动检查与迁移校验分开，单份对象缺失不会阻止打开其他资料，但会阻止生成不完整迁移副本。

包内独立 EXE 的 14 组桌面脚本通过。新增存储脚本验证设置入口、预览取消、实际迁移、重启、旧版迁移；迁移后文档 / 分类 / 收藏 / 标记 / 附件 / 草稿 / 历史 / 主题相同，Office 阅读、文本搜索、复制路径、附件协议、完整备份和文件夹导入均指向新库。其他 13 组继续覆盖文件类型、拖入、编辑、历史对比、备份恢复和分栏等已有能力。

`npm run test:installer-storage` 用生产使用的同一份清理钩子编译最小 NSIS 卸载器，只操作隔离测试目录，验证程序文件被清理而 data、用户额外文件及目录外文件保持原字节。不运行生产安装器、不改动用户安装注册表。未对用户真实安装做覆盖升级；这一测试不代替完整安装流程、跨 Windows 版本或真实断电验收。

## 边界

迁移使用与备份相同的有效对象限制：合计 10 GiB、单对象 100 MiB。不复制未被引用的废弃对象、旧恢复备份和临时文件。暂未提供自动清理旧副本、备份保留策略或跨用户共享文档库。

安装包无签名，安装和运行仍无需联网及额外运行环境。发布仅包含程序与校验文件，不包含个人资料库。
