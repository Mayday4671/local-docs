# 0.7.0 Office 页面与网格编辑验收

日期：2026-09-27。针对用户反馈的 Word 按段落、Excel 按单元格排列成巨大表单的问题，替换编辑呈现；仍为离线 Windows EXE，无新增服务和依赖。

## 使用变化

- Word：“编辑内容”显示文档纸张，点击普通段落或表格中的文字直接修改。原有表格、图片、页眉页脚保留在文档上下文；查找可编辑文字，缩放 75%–150%，在末尾追加新段落。蓝色背景表示有未保存修改，复杂或受保护内容保留为只读。
- Excel：“编辑内容”显示带行号、列字母的网格和工作表标签。点击单元格输入，或在顶部内容栏编辑；Enter 向下、Tab 向右、上下箭头切换格子。查找框可输入文字或地址（如 AA120）；支持已有及空白格，合并区域指向左上角。
- 阅读与编辑可来回切换，未保存的改动仍在草稿中；阅读视图明确提示展示已保存版本。正式保存、历史版本、恢复草稿、原件保护沿用既有流程。

## 数据保护

Word 页面定位使用只供渲染的随机锚点，不按文字或页面中的段落顺序猜测位置。普通段落必须在渲染后与原文一致才能编辑；重复文本分开定位。临时锚点不写入正式文件，保存只修改允许的文字节点。既有未改文字片段属性和其他 ZIP 部件保留。

Excel 后端重复校验真实工作表路径、坐标范围、合并从属格、保护状态和数组公式区域。新增单元格按行列顺序写入，保留工作表其他结构；修改后继续清除过期公式缓存，保留公式表达式及计算设置。无效改动拒绝提交，旧对象与版本仍可恢复。

没有数据库 schema 变化。测试使用独立文档库与程序生成的样本，没有读取、导出或修改截图中的真实用户资料。

## 验证范围

- 59 项单元测试通过：包含重复段落锚点隔离、正式文件无临时标记、新增格子行列顺序、空工作表、空行、旧范围缓存、合并从属格、未知工作表、坐标越界及受保护 / 数组公式空白区域拒绝。
- `office-layout-smoke.mjs` 在实际 Electron 中验证页面文字和表格文字修改、混合粗体保留、清空段落后重新输入、Word 查找与缩放、网格编辑、空白格、合并格、Tab / Enter、AA120 定位、工作表切换、公式只读、草稿在阅读切换及重启后的恢复、保存导出、浅深主题和 1000 px 窗口。断言无 HTTP/HTTPS 请求、无页面异常、导入源文件字节不变。
- `verify-office-layout.py` 用独立 python-docx / openpyxl 复读实际导出文件，确认段落、表格文字、粗体、图片、页眉、未改部件字节、普通 / 新增 / 稀疏格子、隐藏工作表、合并区域及公式表达式；旧公式结果为空，未冒充重新计算。
- 类型检查、格式检查、生产构建及 NSIS 打包通过。包内 EXE 的完整回归结果记载于 [Windows 交付说明](Windows交付说明.md)。

## 仍然受限的功能

这是内容编辑界面的改进，尚未接入完整 Word / Excel 编辑引擎。Word 不提供字体排版工具、图片或表格结构编辑；含图片、域、修订、换行和保护结构的段落仍不可修改。渲染分页可能与原生 Word 不同；实际 Windows 中文输入法候选窗未专项验收。

Excel 当前编辑普通文字和原始数值；日期 / 百分比在未编辑时按已有显示值呈现，进入编辑时显示原始数值。新写入的空白格采用默认单元格样式。尚不提供完整字体 / 背景样式呈现、公式编辑与计算、图表、条件格式、工作表及行列结构编辑或多格粘贴。每次显示 40 行 × 12 列，可翻页或直接定位；编辑保存仍受现有文档解析上限限制。

样本验证不等于任意复杂 Office 文档兼容认证。没有关闭用户当前窗口或覆盖安装；安装升级向导和跨 Windows 版本未在本轮重新验收。
