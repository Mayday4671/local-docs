# 0.10.8 文本语言识别与高亮验收

日期：2026-10-02。

## 用户行为

SQL / JSON 等文件打开后自动选择对应语法，并以不同颜色显示关键字、字符串、数字、注释和属性。首页预览和阅读页复用同一组件，顶部显示识别语言。浅色、深色及跟随系统主题同步切换颜色；未增加重复的编辑入口，文本继续只读。

扩展名优先，支持 SQL、JSON / JSONL、XML / HTML、YAML、INI / TOML / Properties、JavaScript / TypeScript、CSS / SCSS / Less、Python、Java、C / C++ / C#、Go、Rust、Ruby、PHP、Shell / Batch / PowerShell、LaTeX 等已有文本类型。Vue / Svelte 使用含嵌入脚本的 XML 语法。普通 TXT 可识别完整 JSON 对象 / 数组、结构明确的 SQL、XML / HTML 声明以及 Python / Shell / Node 解释器声明；不以任意关键字把自然语言猜成代码。CSV、TSV 和日志保留普通文本显示。

## 字符与数据保护

沿用现有 UTF-8、带 BOM 的 UTF-16LE / BE 和 GB18030（兼容 GBK 中文）解码；语言识别发生在正确解码之后，不是猜测字符编码的替代品。着色不重新排版、不改空格、Tab、CRLF、中文或原文件。

语法引擎输出文字与样式类别，以 React 文本节点呈现；不注入 HTML、不执行脚本、SQL 或文档中的链接。文内查找与标记仍依赖同一份连续原文，跨多个颜色片段的范围也可以定位、复制和保存标记。

## 离线和资源边界

采用 [lowlight](https://github.com/wooorm/lowlight) 的文本语法树及 [highlight.js](https://highlightjs.readthedocs.io/en/latest/api.html) 本地语法。版本锁定为 lowlight 3.3.0、highlight.js 11.11.2，Worker 与许可证打入安装包；不运行时下载语言文件。许可证位于 `src/renderer/public/text-syntax-NOTICE.txt`。

在独立 Worker 处理，切换文件或结束处理后释放。超过 262,144 字符、20,000 个文字颜色节点、64 层语法结构，或处理失败 / 超过 5 秒，退回完整普通文本，不显示被截断的代码。文本预览仍沿用 5 MB 上限。没有数据库变更、备份格式变更或原文保存操作。
