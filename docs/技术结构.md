# 技术结构

## 模块

- `src/main/library.ts`：SQLite、文档副本、历史记录、导入导出与数据规则。保持独立于 Electron，便于真实文件测试。
- `src/main/index.ts`：窗口、原生文件对话框、自定义应用协议、IPC 来源检查及单实例控制。
- `src/main/storage-location.ts`：默认目录、旧版迁移、位置配置与复制校验后切换；`build/installer.nsh` 保留安装目录内的资料。
- `src/main/office-service.ts` 与 `office-worker.ts`：按内容哈希缓存 Office 解析结果，串行调度后台线程，并设置超时与堆大小限制。
- `src/main/office-parser.ts`：受限解压与 XML 提取，按工作簿关系解析真实工作表及坐标，不执行宏、外部关系或公式。
- `src/preload/index.ts`：只暴露明确的文档能力，不向页面开放原始 IPC、文件系统或任意路径读写。
- `src/shared/types.ts`：界面和主进程共享的数据契约。
- `src/renderer/src/`：React 界面、Markdown 编辑和阅读。
- `tests/library.test.ts`：使用临时目录和真实 SQLite 测试数据保护。
- `scripts/smoke.mjs`：使用 Playwright 操作实际 Electron 窗口，并重启验证持久化。
- `scripts/office-smoke.mjs`：使用合成 Office 样本验证离线阅读、搜索定位、降级提示及字节保留。

数据库 schema v2 新增 `office_cache`。原 v1 数据就地升级；解析失败同样缓存原因，避免每次选择文件都重复解析。阅读缓存以当前内容哈希为依据，未写入历史版本，不改变修改时间。索引构建和预览不计入最近使用。

Word 版式使用 `docx-preview` 动态加载，在 Shadow DOM 内隔离文档样式；关闭 HTML altChunk、内嵌字体和导航。Office 的压缩包验证在后台线程完成，CSP 禁止远程图片、脚本和文档服务请求。Excel 使用 React 转义文本的数据网格；分页保留实际行列编号，公式只读取表达式和存储的缓存值。

## 保存模型

导入内容按 SHA-256 保存为不可变对象。新内容先写入对象文件并刷新到磁盘，再通过 SQLite 事务更新文档引用和版本记录。旧对象不会因保存被覆盖；事务失败时可能产生未引用对象，但旧文档引用保持有效。

每次正式保存且实际内容变化时生成新版本；相同内容不增加版本。恢复历史版本同样产生新记录。版本号阻止过期编辑覆盖新内容。0.6.0 自动恢复草稿写入独立状态，只有正式保存才进入版本记录。

单独的保存模型不等同于完整备份或断电恢复保证。0.4.0 已新增一致性备份与恢复事务故障测试，见下文；未引用对象整理、全库巡检及真实断电验证仍待补齐。

## 边界

渲染页面启用 sandbox、contextIsolation，关闭 Node 集成。主进程验证 IPC 必须来自主窗口主框架；拒绝新窗口、页面跳转、WebView 和权限请求。生产资源使用 `app://local/` 自定义协议，并校验资源路径。

Markdown 禁止原始 HTML，不加载远程图片，链接暂只显示不跳转。0.6.0 图片经原生解码校验后保存为不可变对象，`app://local/attachment/{documentId}/{attachmentId}` 验证所属关系并按固定 MIME 提供；不开放任意路径读取。

开发服务只绑定回环地址。React 热更新所需的内联脚本许可只在开发模式注入，生产构建继续保留严格的脚本来源限制。

## 版本选择

依赖实际版本锁定在 `package-lock.json`。Electron 44 内置 Node.js 24，本阶段使用 `node:sqlite`，避免引入另一个需针对 Electron 编译的 SQLite 原生扩展。对外只依赖 Library 服务，后续可以更换数据库驱动。

electron-vite 5 的 Vite 对等依赖范围为 5/6/7，因此使用 Vite 7 与对应的 React 插件版本，未直接混用不兼容的最新主版本。

参考：[Electron 发布版本](https://releases.electronjs.org/)、[Electron 安全建议](https://www.electronjs.org/docs/latest/tutorial/security)、[electron-vite 官方文档](https://electron-vite.org/guide/)、[Node.js SQLite 文档](https://nodejs.org/api/sqlite.html)。

## 0.4.0 备份与导出

`backup-format.ts` 定义独立于数据库 schema 的备份清单，验证字段、对象引用和分类拓扑。`Library.backupManifest/applyBackup` 分别采集一致性快照和事务恢复；不加载备份中的 SQLite 文件，不执行外来 SQL。

`TransferService` 使用 yazl / yauzl 流式打包、逐条解包。ZIP CRC 校验清单及条目，SHA-256 校验每份内容；白名单路径、数量 / 体积上限和暂存二次校验保护恢复。写入元数据前先落盘不可变对象，恢复失败由 SQLite 回滚，自动安全备份另存于应用数据目录的 `recovery-backups`。

主进程对普通 IPC 串行处理，维护状态和取消接口独立响应。恢复后切换请求代次，拒绝恢复前排队的旧请求。`StorageTools.tsx` 提供备份恢复入口、预览确认、进度和结果路径；`App` 在整体恢复后清除旧的编辑、搜索和选择状态，并重新读取主题。分类导出使用普通目录和独立映射清单，排除回收站。

细节、范围和复现见 [0.4.0 验收记录](0.4.0备份恢复与导出验收.md)。

## 0.5.0 分类整理与文件夹导入

`Library` 新增分类改名 / 移动 / 删除及批量文件移动。分类变动验证树结构、同级名称和 128 层上限；删除子树及文件转移在单一事务内提交，回收站、内容引用和版本保持原状，无需数据库升级。

`FolderImportService` 保存由原生目录选择器生成的只读扫描计划。界面只取得预览与一次性令牌，不传入任意源文件路径。异步扫描跳过链接及应用数据目录；导入前和读取后检查路径、文件标识、大小与修改时间。读取有上限，已有记录不覆盖；重复策略结合名称与内容摘要，自动编号副本也可在重试时跳过。

分类先建立，文件逐个独立提交，取消时保留已完成的部分并返回结果。状态 / 取消复用现有维护接口；活动任务阻止其他 IPC 和窗口关闭。Office 索引延迟到首次阅读或内容检索生成。内容摘要与对象提交仍同步执行，不能将异步读取宣称为完整后台导入。

`OrganizationDialogs.tsx` 提供分类管理、删除影响确认、批量移动、目录导入预览与结果。弹窗隔离底层交互，支持焦点约束、Esc、浅深主题与小窗口滚动。`tests/organization.test.ts` 和 `scripts/organization-smoke.mjs` 验证数据保护和真实桌面操作。

## 0.6.0 阅读标记与基础编辑

schema v5 的 `document_state` 按文档保存经 `document-state.ts` 校验的标记、图片附件和草稿。文档删除时级联清理记录；回收站保留。完整备份格式 v2 加入状态和附件对象，v1 仍可恢复；导出附件验证同名文件内容且不覆盖异内容。

`ReadingPane.tsx` 以正文范围、摘录及前后文锚定标记，用 CSS Highlight API 呈现，不改 DOM 正文。重复片段不唯一时拒绝误定位。Word 按段落、Excel 按工作表与真实地址定位。Markdown 组件使用 memo 避免标记绘制触发宽表反复重建。文内查找限当前已渲染内容，最多显示 1000 处命中。

`office-edit.ts` 先沿用包验证和展开上限，随后仅替换允许的文本位置。Word 保留文字片段的属性与未修改部分；Excel 保留单元格属性、公式与未改部件，修改输入后清除公式缓存并请求重算，保留既有计算选项。复杂结构、数字签名、受保护内容和公式不改写。新文件使用最小 OOXML 包；此方式不是完整 Office 编辑引擎。

`OfficeEditor.tsx` 展示可编辑段落 / 单元格并将改动序列交给 App 管理。App 停止编辑约 800 ms 后保存恢复草稿，正式保存前等待已发出的草稿请求，保存成功清理草稿。恢复时验证版本；回到原内容时清理遗留草稿。内容编辑包处理目前为同步，阅读解析仍通过后台线程。

`tests/content-tools.test.ts`、`scripts/content-smoke.mjs` 覆盖新增流程，`scripts/verify-office-exports.py` 使用独立文档库复读合成导出文件。详情见 [0.6.0 验收](0.6.0收藏标记与内容编辑验收.md)。

## 0.6.1 Markdown 编辑分栏

`EditorSplit.tsx` 用独立局部状态和 CSS Grid 调整编辑 / 预览宽度，拖动不会重新创建编辑器或重置文本。Pointer Capture 让鼠标移出分隔条后仍能拖动；支持双击 / Enter 均分、方向键微调和 Escape 取消拖动。分隔条提供键盘焦点及宽度比例的无障碍语义。

两栏通常可在 20%–80% 间调整，并按 280 px 最小宽度动态收紧范围。ResizeObserver 根据窗口和历史面板占用重新计算可用范围；缩窄时不覆盖原偏好，空间恢复后重新应用。比例写入本机 localStorage，返回文档和重启继续使用；它是界面偏好，不进入正文、历史或文档库备份。读写偏好失败时仍可调整，异常值回退为均分。

`scripts/editor-split-smoke.mjs` 通过真实 Electron 鼠标和键盘验证拖动、边界、重置、取消、小窗口 / 历史面板、浅深主题、未保存文字及滚动位置保持、重启记忆与异常偏好回退。

## 0.6.2 首页预览调宽

将通用拖动逻辑提取到 `ResizableSplit.tsx`，`EditorSplit` 保留原接口和存储键。首页使用独立键 `local-docs:library-preview-ratio`，默认约 61.6% 文件列表 / 38.4% 预览，两侧最低 330 px，依可用空间限制拖动范围。预览收起时文件列表填满区域，保留当前比例；左侧分类导航不参与调整。

首页分栏内部状态更新不重建文件列表、阅读器或备注表单，避免丢失勾选、滚动位置和未保存备注。列表和预览使用容器查询，根据实际面板宽度隐藏次要列、排列操作按钮，不依赖整个窗口宽度。

`scripts/library-split-smoke.mjs` 验证空状态及三种格式预览、拖动 / 重置 / 键盘、收起展开、窗口变化、浅深主题、列表网格、选择和未保存备注保持，以及首页和编辑页比例独立、重启持久化。数据模型未改变。

## 0.7.0 Office 编辑呈现

`OfficeEditor` 负责读取编辑模型、切换阅读与编辑、统一管理原有 `OfficeChange[]` 草稿。`WordEditor` 使用仅供渲染的文档副本添加随机书签锚点，经 docx-preview 渲染后，以锚点和原始文字一致性双重验证位置。允许的普通段落使用独立 plaintext-only 编辑区；既有图片、表格、页眉页脚保留上下文，输入与草稿实时同步。失焦时将文字差异重新应用到原始文字片段，保留未改格式。保护内容不激活编辑；保存继续对原始 OOXML 按字段补丁，不保存预览 DOM 或临时锚点。

`SheetEditor` 显示连续真实行列坐标，每页 40 行、12 列；跨页合并格按可见部分裁剪并指向原始左上角。支持工作表切换、输入栏、坐标及内容查找、Enter / Tab / 上下方向键切换。编辑模型包含工作表真实内部路径及只读范围；后端重复验证保护、合并从属格、公式区域和坐标边界。新增空白格按行列顺序插入，更新可选范围缓存；公式仍保留表达式并清除过期结果，不实现重算。

新增位置锚点、空白格及保护单元测试，以及 `scripts/office-layout-smoke.mjs` 实际桌面回归；`scripts/verify-office-layout.py` 独立复读导出。未引入新依赖，没有数据库迁移。此版本改进编辑界面与空白格输入，仍不提供完整 Office 排版引擎。

## 0.7.1 Word 可编辑性和成功提示

判断段落复杂性时，将 `w:pPr` 段落属性和正文内容分开：段落制表位 `w:tabs/w:tab` 属于格式，不能因为与正文制表符同名就锁定整个段落。没有文字节点的普通空白段落允许输入，保存时添加文字 run 并保留段落属性及表格结构。正文制表符、换行、域、图片、修订和实际保护区域继续受限，位置键保持不变以兼容已有草稿。

App 的成功提示增加单调序号，每次操作完成后显示 3000 ms；同文案再次出现也重新计时。清理旧定时器并检查序号，避免较早回调关闭新消息。错误和处理中状态不走成功提示的自动关闭流程。

## 0.8.0 历史对比与直接编辑

新增 `readVersion(documentId, versionId)` IPC，主进程先验证版本归属文档，再读取不可变对象。Markdown 沿用 UTF-8 和体积验证；Office 沿用受资源限制的后台解析队列，不写当前文档索引，不变更正文、版本、最近使用或草稿。读取异常在对比窗口内呈现并提供重试。无数据库迁移或新依赖。

`version-diff.ts` 对 Markdown 行与 Word 部件内段落执行内容对齐：共同首尾、总计最多 100 万矩阵格的 LCS、较大文档的唯一内容锚点与最长递增子序列；大量重写无法细分时退化为位置配对并提示。Excel 根据真实工作表名及单元格地址比较显示值、原始数值、公式和工作表顺序、可见性、合并范围。相同文字不意味着字节相同，结果同时检查内容摘要并明确非文字差异边界。

`VersionComparison` 使用原生模态 dialog 隔离背景交互；左右版本选择、仅看差异、每页 100 项、浅深主题和小窗口布局。异步读取防止旧请求覆盖新选择，缓存最多 6 个版本。关闭和 Escape 返回原按钮；对比期间 Ctrl+S 不保存背景文档。

首页的打开意图传到 `OfficeEditor.initialMode`：显式编辑与新建直接进入编辑，普通打开 / 双击保留阅读及搜索命中定位。阅读和编辑切换仍可使用，草稿与正式保存流程不变。

## 0.8.1 Office 状态与操作分离

`OfficeEditor` 去掉并列的“阅读与标记 / 编辑内容”按钮，以不可点击的文字展示“编辑中 / 阅读中”，只显示切换到另一状态的操作。首次阅读时操作为“编辑”，进入过编辑后再阅读则为“返回编辑”。状态切换复用原有编辑模型、修改集合和草稿，不自动保存正文。等待操作及草稿恢复选择时禁止切换。沿用已有桌面回归验证 Word / Excel、新建、保存、草稿、标记和历史流程。
