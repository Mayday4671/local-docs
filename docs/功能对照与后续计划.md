# 功能对照与后续计划

核对日期：2026-09-28。代码版本：0.10.0。

依据：重新读取聊天「设计在线文档系统原型」中的主设计交付说明和 V1.1 用户视角复审，结合已保存原型、[开发基线](开发基线.md)、当前界面和主进程实际接口。原始完整附件仍不可取得，以下不冒充原版 40 项验收和 15 项新增场景的逐条验收。

0.6.0 补齐显式收藏、内容标记与备注、恢复草稿、Markdown 图片附件、文内查找，以及 Word / Excel 基础内容编辑与新建。0.10.0 补齐默认安装目录存储与设置内换盘；完整 Office 排版编辑、定期备份等尚待实现。

## 已实现的主要流程

- Windows EXE、离线运行、无需登录；手动添加文件，保管独立副本，不修改原件。
- 原型的三栏界面、可收起预览、分类树、列表 / 网格、信息 / 标签页。
- 多级分类创建、改名、移动和删除；删除分类可将文件转移到指定位置，保留回收站状态与历史；文档改名、批量移动、收藏、标签和备注；多选移入回收站。
- 文件夹导入：目录与数量预览、保留空分类、进度和取消、重复跳过或保留副本、失败清单。取消后保留已导入内容，可重新选择同一目录继续。
- 文件名、正文、标签和备注检索，短中文查询、类型筛选、命中摘要；Word 段落和 Excel 真实单元格定位。
- 查看本批导入文件；快速预览不计入最近使用；返回列表保留查询、筛选与浏览上下文。
- Markdown 编辑、表格预览、手动保存、历史版本及恢复；单文件导出、回收站恢复。
- Word 只读版式 / 正文、Excel 多工作表只读网格；主题三种模式及持久化。
- 完整备份包含文件、分类、标签、备注、收藏、回收站、历史和主题；恢复前展示清单并自动保留原库备份，失败回滚。可在另一份独立文档库恢复用于换机迁移。
- 按分类（含子分类和空分类）或整个文档库导出普通文件夹，处理重名并生成结果清单。
- 列表星标、批量收藏、阅读页收藏；Markdown / Word 正文选字与 Excel 单元格高亮，支持四色、备注、集中查看、检索和定位，不改写原文。
- 编辑停止约 800 ms 自动存恢复草稿，下次打开可恢复或丢弃；正式保存才生成版本。Markdown 本地图片导入和粘贴截图，附件随导出及备份保存。
- 新建 Word / Excel；Word 普通段落修改与末尾追加，Excel 已有普通单元格修改；内容保存生成新文件版本，旧版和导入原件保留。
- 0.6.1 支持 Markdown 编辑 / 预览两栏拖动调宽、双击恢复均分与重启记忆；历史版本面板打开及窄窗口时保留可用宽度。
- 0.6.2 支持首页文件列表 / 文档预览调宽、收起展开保留比例及重启记忆，与编辑页独立；侧栏分类宽度保持原状。
- 0.7.0 用 Word 页面内改字、Excel 行列网格取代逐项表单。Word 保留纸张、表格和图片上下文，提供查找与缩放；Excel 显示合并格、填写空白格、键盘切换与坐标定位，保存及草稿沿用原有保护流程。
- 0.7.1 修复 Word 段落制表位格式误判为只读，支持空白普通段落输入；进入编辑时定位可编辑正文。成功提示 3 秒后自动关闭，连续操作重新计时；错误与处理中提示不自动消失。
- 0.8.0 新增已保存版本的内容预览与左右差异：Markdown 按行、Word 按段落、Excel 按工作表 / 单元格与公式比较；保留未保存的正文与草稿。首页“编辑”和新建 Office 文件直接进入编辑状态。
- 0.8.1 移除 Office 编辑状态下的重复按钮，以文字标识当前状态；编辑时提供“阅读与标记”，阅读时提供“编辑 / 返回编辑”，切换保留修改。

- 0.9.0 新增 PDF、文本、SQL、图片等格式收纳与只读预览；支持文件拖入、文本搜索和标记，其他格式原样收纳。移除侧栏“未分类”，无分类文件在“全部文件”查看。

## 原设计与复审中尚未完成的部分

### 1. Word、Excel 基础内容编辑已实现；完整编辑仍有缺口

0.7.0 可以在 EXE 内新建、打开、编辑、保存和重开。Word 可在页面内修改普通段落和表格文字并追加正文；Excel 提供真实坐标的行列网格，可改普通单元格和填写空白格。保存加入历史，原件保持不变，正式保存失败不替换旧内容。合成样本的导出已用独立的 python-docx / openpyxl 复读。

仍缺完整可视化排版、Word 表格结构编辑、工作表 / 行列增删、图表及公式编辑和重算。含图片、域、修订、换行或受保护结构的 Word 段落禁止修改；Excel 公式和受保护内容只读。修改 Excel 输入值后清除旧公式缓存并要求重算。不能将这一受限编辑方式称为完整 Office 引擎交付。

### 2. 备份、恢复与换盘已实现；定期备份待补

0.4.0 已实现手动完整备份、校验预览、确认后恢复、恢复前自动备份及跨独立文档库恢复。0.10.0 默认存储在安装目录下，设置中可选空文件夹迁移，复制校验后即时切换，保留旧副本，重启记忆；失败继续使用原库。旧版资料自动迁入默认位置，升级 / 卸载清理保留安装目录的 data。定期备份、备份清理管理和手动重建索引尚未实现。

换机方式为“创建备份 → 在新电脑安装本应用 → 选择备份恢复”。换盘直接通过“设置 → 修改位置”。验收详情见 [0.4.0 备份恢复与导出验收](0.4.0备份恢复与导出验收.md) 和 [0.10.0 存储位置验收](0.10.0存储位置验收.md)。

### 3. 分类管理与批量移动已补齐

0.5.0 新增分类改名、移动和整棵子树删除，拒绝循环与同父级同名冲突。删除确认显示受影响分类、正常文件及回收站文件数量；文件移动到指定分类，不删除内容或历史。批量移动统一校验并在事务中提交，任何无效项都会阻止整批修改。

分类结构删除后没有单步撤销；如需恢复原有结构，可使用删除前的完整备份。分类合并、拖动排序仍可作为后续增强。

### 4. 文件夹导入与拖放

0.5.0 已支持主动选定文件夹、预览数量与目录、映射分类并保留空文件夹。同名分类复用；同分类、同名（含自动编号副本）且内容相同可跳过，或选择全部保留；不同内容自动编号。导入失败单独列出，可修正后重新选同一目录重试。单独多选文件的旧入口仍按每次新增副本处理。

0.9.0 支持将多个普通文件拖入首页当前分类，导入后可逐项查看失败原因；目录仍通过“导入文件夹”流程处理。文件夹导入有数量、体积和深度上限；只读取用户选定的来源，不自动扫描电脑或监控原目录。详细限制与验收见 [0.5.0 验收记录](0.5.0分类整理与文件夹导入验收.md)。

### 5. 自动保存和有意义的恢复节点

0.6.0 已实现 Markdown 和 Office 编辑恢复草稿；每次停止输入约 800 ms 写入，强制退出后可恢复。草稿独立于正式文件和版本，不密集生成历史。正式保存、明确丢弃或撤回全部修改后清理草稿。尚未写入的最后一段输入不能保证恢复。

0.8.0 已实现内容预览 / 差异对比，可选择任意两个已保存版本；字体、排版、图片及图表的可视化差异仍待实现。会话分组和保留策略尚未实现，目前所有正式版本保留，不自动清理。

### 6. 批量导出与按分类带走资料

已支持单文件、按分类和整个文档库导出；子分类和重名处理保持原流程。0.6.0 加入 Markdown 图片附件随导出保存，使用可移植的相对路径。内容标记、恢复草稿和历史通过完整备份保留，普通文件导出不嵌入这些信息。多选文件导出 ZIP 尚未实现。

完成条件：导出目录结构和正常文件名，解决重名，输出结果清单，附件一起带走；明确“导出文件”与“备份文档库”的用途不同。

### 7. 搜索与文档内查找仍有缺口

已支持分类上下文、类型筛选、正文片段、Office 定位及标记 / 备注检索。0.6.0 新增 Markdown 搜索词高亮和文内查找、逐处导航；Office 文内查找限当前显示页。仍缺修改日期范围、替换、文件名高亮、大库性能验收和索引修复入口。

完成条件：搜到后直接看到具体命中位置；支持“最近一个月的 Excel”等组合筛选；用大库样本验证速度。索引方案升级必须保留一两个汉字查询。

### 8. Markdown 附件和编辑体验

0.6.0 已支持本地 PNG / JPEG / WebP 和粘贴截图，图片经验证后纳入对象库，以相对附件路径写入 Markdown，随备份和导出保存。未纳入管理的原有相对图片和远程图片仍显示占位；编辑器仍为源码与预览并列。

后续可增加导入 Markdown 时的同目录附件打包、附件清理管理和更多编辑工具栏。

### 9. 文档显示与 Windows 交付仍需专项完善

Word 复杂分页、域、修订仍可能与原生软件不同；Excel 编辑网格呈现合并区域，阅读网格仍提示范围，图表、条件格式和完整样式尚未呈现，公式不重算。已验证草稿突然退出恢复；真实断电、跨版本覆盖安装、大量文件和磁盘不足仍缺专项验收。

## 设计文字与原型的三处不一致

原聊天的设计说明曾明确：按钮叫“新建分类”，“全部文件”与具体分类不同时高亮，右栏主要操作为编辑 / 导出。后来提供的原型图则仍有“新建文件夹”、双重高亮和显眼的复制内部路径；当前界面按用户后来要求还原的原型实现。

这三项不应当笼统算作功能已完成。建议下一轮统一为“分类”的概念、单一导航高亮，并将导出提升到右栏主操作。库内对象路径是无扩展名的内部文件地址，也不是方便分享的正常命名文件；日常场景优先提供导出或“在文件管理器显示导出文件”。本轮先记录，不擅自改动其他界面。

## 可扩展的方向——不是已确认必做范围

1. **PDF 阅读增强。** 0.9.0 已完成 PDF、图片和常见文本收纳、分类、导出和只读预览；后续可补 PDF 全文索引、跨页查找与扫描件 OCR。
2. **保存筛选条件。** 例如“工作资料 + Excel + 最近 30 天”保存为快捷入口；与实体分类分开，不复制文件。
3. **重复文件整理。** 基于现有内容摘要识别完全相同的文件，先展示建议；由用户决定是否合并记录，并处理分类、标签和版本的保留。
4. **阅读舒适度。** 编辑页和首页列表 / 预览均已支持拖动调宽；字号、缩放、长期记住阅读位置与文档大纲仍可继续完善。
5. **离线 OCR。** 在 PDF / 图片支持之后，为扫描件和截图提取可搜索文字；应展示识别来源与误差，保持本地处理。
6. **模板和文档关联。** 常用会议记录 / 项目说明模板，以及资料之间的链接；作为整理能力稳定后的增量。

暂不建议优先做账号、云同步、多人协作、权限后台或 AI 聊天。这些会扩大维护范围，也偏离目前“个人离线 EXE”的产品约束；若未来需要，再单独设计。

## 建议推进顺序

1. **已完成首轮数据可恢复、可带走：** 0.4.0 完成一致性备份 / 恢复、分类导出；0.10.0 完成换盘与安装目录默认存储。定期备份和大库压力测试继续保留。
2. **同时尽早完成 Office 可行性验证：** 先明确离线编辑与保存是否达到要求，避免将核心不确定性拖到最后；这一步验证方案，不承诺尚未确认的引擎成本或交付日期。
3. **已完成首轮日常整理：** 0.5.0 补齐分类管理、文件夹导入、批量移动和导入重复处理；0.9.0 补齐普通文件拖入，分类撤销与大库性能继续保留。
4. **继续完善编辑与查找：** 0.6.0 已完成恢复草稿、图片附件、文内查找与基础 Office 内容编辑，0.8.0 补齐版本内容比较；后续实现日期筛选、全文定位与完整 Office 排版编辑。
5. **再扩展辅助格式和阅读效率：** 0.9.0 已补 PDF / 图片与文本；后续保存筛选、阅读位置，最后评估 OCR 等能力。

当前可继续使用作基础文档库，但不能据现有界面完整就宣布 V1.1 已全部交付。
