# 0.6.0 收藏、标记与内容编辑验收

日期：2026-09-27。测试仅使用合成文件和独立文档库，不读写用户日常资料。

## 本轮新增

- 收藏入口：列表星标、阅读页收藏、批量收藏、收藏列表取消所选收藏。数据库已存在的收藏记录继续沿用。
- 内容标记：Markdown 选中文字、Word “正文”中的单段文字、Excel 单元格；四色高亮、备注、修改与删除、侧栏集中查看、原位置跳转和全文检索标记 / 备注。原文改变后若不能唯一匹配，保留摘录并提示，不随意跳到同名文字。
- 恢复草稿：停止编辑约 800 ms 自动写入独立记录。重新打开可恢复或丢弃，离开编辑页可保留草稿；正式保存才生成历史版本。撤回所有修改后清理旧草稿。正式版本发生变化时拒绝套用旧 Office 草稿。
- Markdown 附件：插入本地 PNG / JPEG / WebP、粘贴截图，解码校验后规范为 PNG；使用相对路径，随单文件和分类导出带走，随完整备份恢复。
- Word / Excel 新建与基础内容编辑：列表菜单进入。Word 可改普通段落、页眉页脚普通文字、表格中的普通文字和末尾追加正文；Excel 可改已有普通单元格文字 / 数值。新工作簿提供 20 行 × 8 列起始区域。保存产生真实 DOCX / XLSX 新版本，原件与旧版本保留。
- 文内查找：当前显示内容高亮并逐处导航；Markdown 搜索结果打开后带入查找词。Office 查找限当前页，Word 需使用正文视图。
- 修正阅读区重新渲染导致 Markdown 表格滚动位置重置的问题；浅色和深色使用统一阅读样式。

## 数据与版本保护

schema v5 新增文档状态，旧 schema v4 自动升级。标记、草稿和图片引用独立于原文件；收藏和标记不产生正文版本。批量收藏全部校验后事务提交。正文保存沿用版本冲突检查与不可变对象保存；原件不覆盖。草稿、标记和附件同属备份格式 v2，仍可恢复旧 v1 备份；旧应用不支持 v2。

普通文件导出包含当前正文与图片附件，标记不会嵌入 DOCX 或 Markdown。要保留标记、草稿、分类关系和历史，请用完整备份。导出附件遇到同名不同内容时拒绝覆盖。

## 当前边界

这是基础内容编辑，不是完整 Word / Excel 引擎。Word 不支持字体排版、表格结构调整，含图片、域、修订、换行或受保护结构的段落禁止改写。Excel 不提供工作表 / 行列增删、公式编辑、图表和公式计算；公式 / 数组结果区域及受保护单元格只读。修改输入值后清除缓存，保留计算设置并加重算标记，需支持重算的软件计算新结果。

部分修改跨越 Word 多个格式片段时，插入文字沿用插入处的格式；未修改 ZIP 部件字节保留。不能据合成样本宣称任意 Office 文档保真。编辑操作采用与阅读相同的包体积 / 展开上限，目前在主进程处理，大文档可能短暂阻塞。

标记每文档最多 500 条，单次摘录最多 8000 字符、备注最多 5000 字符；不支持跨 Word 多段选区。图片每张最多 10 MiB 和 1600 万像素，每文档最多 200 张；原有相对图片需手动纳入库内。草稿最大 5 MiB；突然退出时尚未完成自动写入的输入不保证恢复。未做真实断电、磁盘耗尽、复杂真实 Office 样本和大量文档压力验收。

拖放、日期筛选、定期备份、存储目录切换、PDF / 独立图片预览、版本比较与清理等仍在 [后续计划](功能对照与后续计划.md)，不列为已完成。
