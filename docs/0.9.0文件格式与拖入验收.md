# 0.9.0 文件格式与拖入验收

日期：2026-09-28。使用隔离文档库和合成样本；不读取、打包或上传用户资料库。

## 使用变化

- “添加文件”默认可选择所有普通文件；文件夹导入也不再限制为三种文档。
- PDF 在侧栏和完整阅读页离线显示，可翻页、缩放和复制本页文字；中文 CMaps、标准字体、解码器和 worker 随 EXE 打包。
- TXT、SQL、CSV、JSON、XML、YAML、日志、常见代码与配置文件按纯文本显示，保留缩进换行，支持内容搜索、文内查找与标记；SQL、HTML 和脚本不会执行。
- PNG、JPEG、WebP、GIF、BMP 提供图片预览；其余格式保存原文件，显示导出入口，不误进 Office 编辑器。
- 在首页拖入多个文件，显示目标分类并复制到本地库。成功和失败逐项处理，导入成功后清除旧筛选以显示新资料。来源文件不移动、不删除。
- 侧栏移除“未分类”。已有未指定分类的文件仍可在“全部文件”查看；删除分类或移出分类后也返回全部文件。按分类导出的无分类文件目录名沿用旧版本兼容行为。

## 范围与限制

- 单个文件最大 100 MB；Markdown 仍为 UTF-8、最大 5 MB。单独添加 / 拖入每批最多 500 份、2 GiB；目录导入沿用每批 5000 文件、2000 目录和 2 GiB 等限制。
- PDF / 图片内置预览最大 30 MB；普通文本预览与索引最大 5 MB，识别 UTF-8、带 BOM 的 UTF-16 和 GB18030。超出预览范围、编码无法识别或包含二进制数据时仍可保存原文件并导出。
- PDF 当前为只读阅读，没有正文全库索引、跨页查找、内容标记、OCR、表单填写和内容编辑；加密 PDF 提示导出后使用本地软件阅读。TXT / SQL 等新增类型当前也为只读。
- 目录请使用列表菜单中的“导入文件夹”；编辑页、弹窗、处理中和回收站不接受文件拖入，防止打断未完成操作。文件拖入采用 Electron `webUtils.getPathForFile` 取得真实本地文件，构造的网页 File 不会被当作磁盘路径。
- 保持数据库 schema v5、备份格式 v2；旧备份可继续恢复。包含新增格式的备份需使用 0.9.0 或更新版本，旧版本的类型白名单会拒绝它们。
- 新电脑可用 U 盘携带 EXE 离线安装，不需要下载 PDF 字体、运行环境或插件。安装包为未签名测试版；本次未覆盖安装用户正在运行的程序，未重复跨 Windows 版本或实际覆盖升级验收。
