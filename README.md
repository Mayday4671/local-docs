# 我的文档库 · local-docs

个人离线文档管理桌面应用。使用 React、TypeScript、Electron 和 SQLite；无需登录，不部署独立后台。

仓库：<https://github.com/Mayday4671/local-docs>

## Windows 安装使用

**[下载 0.10.1 Windows 离线安装包](https://github.com/Mayday4671/local-docs/releases/download/v0.10.1/local-docs-0.10.1-x64-setup.exe)** · [更新与安装说明](https://github.com/Mayday4671/local-docs/releases/tag/v0.10.1)

适用于 Windows 10 / 11 x64。下载 EXE 后双击进入中文安装向导，安装后从开始菜单打开“我的文档库”。安装和日常使用无需联网，也无需另外安装 Node.js、npm、数据库服务、Office 或 WebView2；离线电脑可通过 U 盘携带安装包。普通使用不需要下载 GitHub 自动生成的 Source code。

本地构建产物位于 `release/0.10.1/local-docs-0.10.1-x64-setup.exe`。安装文件夹名为英文 `local-docs`；通过“浏览”选择 `D:\Soft` 后，路径框自动显示 `D:\Soft\local-docs`。发布包不包含用户资料库或个人文档，新电脑首次运行在安装目录的 `data/library` 下创建空文档库；换机请通过应用的“完整备份 → 恢复”迁移资料。

这是 **0.10.1 测试版 EXE**。修复安装向导“浏览”后没有显示应用子目录的问题。文档库默认放在安装目录下，“设置 → 文档库位置 → 修改位置”可迁移到其他磁盘，复制校验后立即切换并保留旧副本。旧版资料自动迁入默认位置，失败时继续使用旧库。PDF、TXT、SQL、图片收纳与阅读、文件拖入等已有功能保留。完整 Office 编辑和 V1.1 全部要求尚未完成。安装包未做数字签名，附有 SHA-256 校验文件。验证范围见 [Windows 交付说明](docs/Windows交付说明.md)。

## 当前阶段

**0.10.1 开发测试版，尚未完成 V1.1 验收。**

已有可运行流程：

- 按补充原型重做的蓝白桌面界面：顶部统一搜索、分类树、紧凑列表和右侧文档预览。
- 浅色、深色、跟随系统三种主题；通过主界面和阅读 / 编辑页右上角的主题按钮切换并自动记忆。
- Markdown 表格、任务列表、删除线和代码块；侧栏与编辑页使用同一套渲染。
- Excel 侧栏直接显示单元格网格，支持日期、百分比、千分位和自定义补零格式。
- 多级分类、新建子文件夹、列表 / 网格切换、多选移入回收站；预览 / 信息 / 标签页。
- 分类旁“⋮”可改名、移动和删除；删除分类时转移文件，保留回收站状态和历史。多选文件可批量移动。
- 列表“⋮ → 导入文件夹”：先预览再导入，保留目录与空分类，可取消；相同内容默认跳过，重名不同内容自动编号，失败项目逐项列出。
- 标签、备注本地保存并可搜索；复制库内副本路径。
- 批量添加或拖入 PDF、TXT、SQL、CSV、JSON、图片、DOCX、XLSX、Markdown 等文件；其他普通文件也可收纳和原样导出。保存独立副本，不修改导入源文件。
- PDF 离线翻页、缩放和复制本页文字，阅读组件、字体及 CMaps 随 EXE 打包；常见图片内置预览。
- TXT、SQL、代码与配置文件以纯文本阅读，保留缩进和换行，支持正文搜索、文内查找与内容标记；不会执行 SQL、HTML 或脚本。
- 首页拖入文件时显示目标分类；无分类文件在“全部文件”中查看，侧栏不再提供“未分类”入口。
- 新建分类、移动文档、重命名、收藏；查看本批导入的文件。
- 按文件名、常见文本和 Markdown 正文、Word 段落和 Excel 单元格内容搜索，支持一两个汉字；按类型筛选。
- Word 只读版式 / 正文阅读，Excel 多工作表数据阅读和公式缓存查看。
- 搜索结果显示命中摘要；打开结果可进入 Word 正文中的命中段落，或 Excel 的真实工作表及单元格。
- 新建和编辑 Markdown，手动保存 / Ctrl+S 保存，实时阅读预览。
- 拖动 Markdown 编辑页中间分隔条调整两栏宽度，重启后记住比例；双击或 Enter 恢复均分，左右方向键微调。窄窗口和历史面板打开时自动保护最小可用宽度。
- 首页拖动文件列表与文档预览之间的分隔条，双击或 Enter 恢复默认比例；收起 / 展开预览和重启后记住宽度，与编辑页独立。列表变窄时优先展示文件名，预览按钮随宽度换行，左侧分类栏保持原宽度。
- 列表星标、阅读页收藏、批量收藏和取消收藏。
- Markdown / Word 正文选字、Excel 单元格标记；四色高亮、备注、修改与删除，侧栏“内容标记”集中查看，点击返回原位置。标记与备注可搜索，独立于正文保存。
- 新建 DOCX / XLSX；Word 页面内修改普通段落及表格文字、末尾追加多段正文、查找与缩放。Excel 在行列网格中修改文字或数值、填写空白格、显示合并区域、切换工作表和定位坐标；Enter / Tab 切换单元格。复杂结构和公式保持只读。
- 停止输入约 800 ms 后自动保存恢复草稿；打开时选择恢复或丢弃。正式保存才生成历史版本，草稿不挤占版本记录。
- Markdown 插入 PNG / JPEG / WebP 或粘贴截图；库内管理图片，随文件导出和完整备份保存。
- 文内查找与逐处定位；Office 范围为当前显示的正文页 / 工作表分页。
- 历史版本、版本恢复，删除进入回收站，恢复保留分类。
- 历史版本 → 查看差异：任选两个已保存版本左右对照，显示新增、删除、修改和原位置，可切换“仅看差异”及分页。Word 按段落文字、Excel 按工作表和单元格比较；只读查看，不覆盖当前编辑或草稿。
- 首页“编辑”直接打开 Word 页面 / Excel 网格编辑；“打开”和双击文件进入阅读。新建 Office 文件直接开始编辑。
- Office 编辑时显示“编辑中”和“阅读与标记”操作，不再显示重复的“编辑内容”按钮；阅读时可“编辑”或“返回编辑”，切换保留未保存修改。
- 单文件、分类子树和整个文档库导出；保留正常名称与目录结构，处理重名。
- 完整备份、校验预览、确认恢复和换机恢复；恢复前自动保留当前库备份，失败回滚。
- 文档库默认保存在安装目录的 `data/library`；设置中修改路径，校验后立即生效、重启记忆，取消或失败保留原库。0.10.0 安装包的升级 / 卸载清理保留 `data`。
- 真正打开文件才记录最近使用；快速预览不计入。
- 返回列表保留搜索词、分类、类型筛选及列表滚动位置。

**DOCX / XLSX 已接入基础内容编辑；完整排版编辑、图表和公式计算仍未实现。** 阅读与索引不会重写文件；编辑后生成新版本，导入原件保持不变。

## 本地开发

环境：Windows 10/11 x64、Node.js 24（至少 24.15）与 npm。

```powershell
npm ci
npm run dev
```

首次安装与下载 Electron 需要联网；应用运行和当前文档管理功能不需要联网。开发时启动的是 Electron 桌面窗口，不能把普通浏览器预览当作可用的本地文档库。

若首次启动时 Electron 下载超时，可使用 [Electron 官方安装文档](https://www.electronjs.org/docs/latest/tutorial/installation) 列出的镜像，在当前终端重试（仍使用包内官方校验值）：

```powershell
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
node node_modules/electron/install.js
npm run dev
```

## 数据位置

默认文档库：`<安装目录>/data/library/`。点击左下角“设置”，在“文档库位置”旁点击“修改位置”，选择有写入权限的空文件夹，核对后点击“迁移并使用此位置”。文件、分类、收藏、标记、附件、草稿和历史一起复制校验，完成后立即生效，重启仍使用新位置。旧副本保留，不再同步；取消或失败继续使用原位置。

0.9.0 及更早版本位于 `%APPDATA%/local-docs/library/` 的资料，在首次启动 0.10.0 时自动复制到默认位置。若默认位置不可写、空间不足或已有其他内容，继续使用旧库，并在设置中提示。首次使用的安装目录不可写时，会提示选择可写文件夹；已配置的磁盘失联时提示重新连接或选择已有文档库，不会用空库替换。

- `library.sqlite`：文档信息、分类、搜索文本、历史版本、标记、附件引用、恢复草稿和主题设置（schema v5）。
- `objects/`：按内容摘要保存的不可变文件副本。
- SQLite 使用 WAL；运行时可能存在 `library.sqlite-wal` 和 `library.sqlite-shm`。
- `%APPDATA%/local-docs/storage-location.json` 只记住文档库地址；窗口配置和浏览器缓存仍在该应用配置目录。
- 新产生的恢复前备份位于当前文档库的 `recovery-backups/`；此前已生成的备份留在原位置，不随换盘复制。

安装包升级 / 卸载保留安装目录的 `data` 和应用配置；不要手动删除安装目录里的资料。换机仍使用完整备份。开发时默认使用项目目录下已忽略的 `data/library`；`LOCAL_DOCS_DATA_DIR` 可指定隔离配置目录并将测试库放到其中的 `library`。不要提交文档库，也不要在运行中单独复制 SQLite 文件充当完整备份。

## 当前限制

- 已将用户补充的原型图保存至 `docs/references/local-docs-v1.1-prototype.png`，并完成主界面截图对照，见 [设计验收](design-qa.md)。完整 V1.1 文档附件仍未取得。
- Office 为受限内容编辑，不是完整 Word / Excel。保留未修改的 OOXML 部件；复杂段落、受保护内容与公式禁止改写；不提供字体排版、表格结构修改、工作表增删或公式重算。编辑范围见 [0.7.0 验收](docs/0.7.0Office页面与网格编辑验收.md)。
- 多级分类管理、标签、备注、批量移动、文件夹导入和应用内换盘已实现；多选 ZIP 导出与定期备份尚未实现。
- 文件夹导入每批最多 5000 份文件、2000 个目录、2 GiB，扫描最多 10000 个项目、32 层；跳过链接、应用自身数据目录、超限文件和非常规文件。失败或取消后可重新选择原目录，跳过已导入的相同内容。
- Markdown 仅支持 UTF-8，当前最大 5 MB；其他文件导入单文件最大 100 MB；单独添加 / 拖入每批最多 500 份、2 GiB。Markdown 本地图片需通过“插入图片”或粘贴纳入管理，每张 10 MiB / 1600 万像素以内、每文档最多 200 张；外部图片和未导入的相对路径仍显示占位。
- PDF / 独立图片预览最大 30 MB，TXT / SQL 等文本预览与正文索引最大 5 MB；超过预览上限仍可原样收纳和导出。文本识别 UTF-8、带 BOM 的 UTF-16 和 GB18030；无法识别或包含二进制数据时提示导出。新增格式当前只读，不提供 PDF 编辑、OCR 或 PDF 全库正文索引，PDF 可按名称、标签与备注搜索。
- 拖入目录请改用“导入文件夹”；编辑、弹窗或回收站中不接受文件拖入，避免打断当前操作。
- 草稿自动保存与正式手动保存分开；突然退出最多可能丢失尚未自动写入的最后一段输入。所有历史版本暂全部保留，未实施版本分组与清理策略。
- 历史对比不包含未保存修改。Word 空白段落、字体、排版和图片，Excel 样式、图片和图表暂不展开；Markdown 显示源码及图片引用，忽略换行编码差别。文字相同但文件字节不同会明确提示其他变化。Markdown 两侧合计最多 10 万行，Office 沿用下述解析限制；变化特别大的内容按位置配对并提示。
- 标记每份文档最多 500 条，每条选文最多 8000 字符；Word 标记需切换“正文”。原文变化后找不到唯一匹配时保留原摘录并提示，不能保证任意修改后仍可定位。
- 新版备份格式 v2 包含标记、附件和草稿；兼容恢复 v1，但旧版应用不能读取 v2。普通文件导出包含图片附件，内容标记请通过完整备份保留。含 PDF / TXT 等新增类型的备份请用 0.9.0 或更新版本恢复。
- 搜索暂用 SQLite 字面包含匹配，已支持摘要和 Office 命中定位；未接入 FTS，尚未完成大文档库性能测试。旧库中的 Office 文件在首次内容搜索或阅读时建立索引。
- Office 解析在独立后台线程执行，最长 15 秒；预览限 20 MB 压缩文件、64 MB 解压内容、2,000 个内部文件、单个 XML 8 MB、100 张工作表、50,000 个单元格 / 文本块和约 200 万字符。超限或加密文件仍可原样导出。
- Word 复杂分页、修订和域可能与原生 Word 不一致；Excel 阅读按数字格式显示数值与公式缓存，不重算公式；编辑时输入原始数值。Excel 编辑网格显示合并区域，阅读网格仍提示合并范围；图表、条件格式、字体和完整样式尚未呈现，但未编辑样式在文件中保留。
- 文件夹扫描和读取为异步；内容摘要、对象落盘和 SQLite 写入仍在主进程执行，大文件提交时可能短暂阻塞。Office 阅读解析在后台线程，基础编辑包处理目前在主进程执行并沿用解析上限。
- 备份恢复已通过代表性功能与失败验收，限制为总对象 10 GiB、单对象 100 MiB；备份不加密。大库性能、磁盘耗尽和断电仍需专项验证。
